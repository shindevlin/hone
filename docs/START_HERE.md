# BTCPC Start Here

If you are new, do this first:

1. Open [`/start`](https://btcpc.net/start).
2. Choose an on-chain username and confirm it is available.
3. Create or import your BTCPC account.
4. Save the wallet export file to disk.
5. Open [`/app`](https://btcpc.net/app) and try inference.
6. Start node roles only if you want to run the network locally.

That is the shortest path to a working BTCPC setup.

If an AI agent is helping you, send it to [`/start`](https://btcpc.net/start)
and let it follow the wizard in order. The manifest at [`/start.json`](https://btcpc.net/start.json)
is the machine-readable version of the same flow.
