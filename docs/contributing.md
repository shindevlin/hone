# Contribution Guide

## Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Ensure your code passes all tests and lints.
4. Submit a pull request (PR) with a summary of your changes and any relevant issue numbers.
5. Participate in code review and address feedback.

## Code Style
- Follow the existing code style and conventions.
- Use Prettier or ESLint if configured.
- Write clear, maintainable code with comments where necessary.

## Testing
- Run tests with `npm test` or `yarn test`.
- Add new tests for any new features or bug fixes.
- Ensure all tests pass before submitting a PR.

## Extending Modules
- To add a new feature or support a new chain:
  - Create a new module in the `src/modules/` directory.
  - Follow the structure of existing modules (e.g., Wallet, Staking).
  - Update documentation and add usage examples.
- For questions or help, open an issue or join the community chat.
