By posting the comment below on your pull request, you record that you
have read Section 4 of this project's `LICENSE` and agree to it, for the
contribution in that pull request and for every contribution you submit
to this project afterward.

To sign, post this comment on your pull request, exactly:

    I have read the CLA Document and I hereby sign the CLA

The record is a line in `signatures/cla.json` on this repository's
`cla-signatures` branch: your GitHub username and numeric ID, the time,
and the pull request. That branch is public.
