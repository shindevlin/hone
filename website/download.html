Manual install (Linux)

Downloaded the binary directly? Three steps.

  1. Make it executable: chmod +x btcpc-node-linux-amd64
  2. Move it to your PATH: sudo mv btcpc-node-linux-amd64 /usr/local/bin/btcpc-node
  3. Run it: BTCPC_ACCOUNT=yourname btcpc-node

For a persistent background service (auto-starts on boot), use the one-line installer instead — it sets up systemd automatically.

Verify the binary

Check the binary runs before you install it.

# After downloading to ~/Downloads/
chmod +x ~/Downloads/btcpc-node-linux-amd64
~/Downloads/btcpc-node-linux-amd64 --version

# Expected output:
btcpc-node 0.1.0

Build from source

Requires Rust (rustup). Takes ~5 minutes on first build.

# Install Rust if you don't have it
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone and build
git clone https://github.com/btcpc-network/btcpc
cd btcpc/rust/btcpc-node
cargo build --release

# Binary at target/release/btcpc-node
./target/release/btcpc-node --version
