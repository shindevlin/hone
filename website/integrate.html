One-time setup
1

Install the CLI

curl -fsSL https://btcpc.net/install | bash btcpc --version
2

Check for an existing wallet first

Do not create a new wallet if you already have one — you will lose access to your existing account and any tokens in it.

# Any of these means you already have a wallet — skip to step 5: ls ~/.btcpc/wallet.json 2>/dev/null && echo EXISTS ls .btcpc/wallet.env 2>/dev/null && echo EXISTS echo $BTCPC_ACCOUNT
Already set up? If BTCPC_ACCOUNT is set or either file exists, skip to step 5 to check your balance.
3

Create your account — only if none exists

btcpc wallet create --account <choose-a-name> # Prints a 12-word mnemonic. Save it — shown once, never stored.
4

Register your signing key — only if new account

btcpc key generate btcpc key register --account <your-account> --role posting

Generates ~/.btcpc/key.json and registers your public key on-chain.

5

Verify balance & claim tokens

curl https://btcpc.net/api/balance/$BTCPC_ACCOUNT # {"balance":10.0,"dreams":100000000000} # 1 BTCPC = 10,000,000,000 dreams

If balance is 0, claim the testnet faucet (10 BTCPC — covers ~100,000 average inference calls):

btcpc faucet claim $BTCPC_ACCOUNT
6

Generate an API key

Check if you already have one first:

grep BTCPC_API_KEY .btcpc/wallet.env 2>/dev/null

If BTCPC_API_KEY is missing or empty:

btcpc wallet api-key-gen --mnemonic "your twelve words here" echo '.btcpc/wallet.env' >> .gitignore
7

Set environment variables

BTCPC_ACCOUNT=<your-account> BTCPC_API_KEY=<64-char hex from api-key-gen> BTCPC_API_URL=https://btcpc.net # override for local node # Load from file: export $(grep -v '^#' .btcpc/wallet.env | xargs)
AI Inference

OpenAI-compatible endpoint. Any model Ollama supports. Fee: 100 dreams / token (min 1,000 dreams). Auth required.

→

curl

curl -X POST https://btcpc.net/v1/chat/completions \ -H "Authorization: Bearer $BTCPC_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "messages": [{"role":"user","content":"What is 2+2?"}], "model": "dolphin-llama3" }' # Response includes usage.fee_dreams showing exact cost.
→

JavaScript / any OpenAI client

const res = await fetch(`${process.env.BTCPC_API_URL}/v1/chat/completions`, { method: 'POST', headers: { 'Authorization': `Bearer ${process.env.BTCPC_API_KEY}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ messages: [{ role: 'user', content: prompt }], model: 'dolphin-llama3', }), }); const { choices } = await res.json(); const text = choices[0].message.content;
→

Rust (btcpc-sdk)

let client = BtcpcClient::from_env(); // reads BTCPC_API_URL/KEY/ACCOUNT let resp = client.chat_completions( vec![json!({"role":"user","content":"Summarise this PR."})], None, // None = node's default model ).await?; let text = resp["choices"][0]["message"]["content"].as_str().unwrap_or("");
!

On 402 — claim faucet and retry once

btcpc faucet claim $BTCPC_ACCOUNT

List available models: curl https://btcpc.net/api/node/models

Git Hosting — LinkGit

Push and clone repos directly on the BTCPC chain. Standard git remote — no special tooling needed to clone.

btcpc repo init $BTCPC_ACCOUNT git remote add btcpc https://git.btcpc.net/$BTCPC_ACCOUNT/<repo> git push btcpc main # Anyone can clone with standard git: git clone https://git.btcpc.net/$BTCPC_ACCOUNT/<repo>
Storage Rewards

Nodes that store and serve data earn from the storage pool by submitting a heartbeat each epoch.

# Get current epoch: EPOCH=$(curl -s https://btcpc.net/api/latest | jq .epoch) curl -X POST https://btcpc.net/api/entry \ -H "Content-Type: application/json" \ -d "{ \"type\": \"STORAGE_HEARTBEAT\", \"node_id\": \"$BTCPC_ACCOUNT\", \"bytes_stored\": 1073741824, \"bytes_proven\": 1073741824, \"proof_valid\": true, \"epoch\": $EPOCH }"
Inference Marketplace

For long-running jobs (>30s). Post a job, workers bid, winner runs inference, verifiers confirm. Dynamic pricing via competitive bids.

# Post a job: btcpc inference post \ --account $BTCPC_ACCOUNT \ --model llama3:70b \ --input "Analyse this codebase..." \ --max-fee 100000 # Check status: btcpc inference jobs btcpc inference job <job_id> # Lifecycle: Posted → Awarded → Completed → Verified → Paid
