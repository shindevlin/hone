One-time setup
Seven steps from zero to a working account, API key, and first inference call.
1
Install the CLI
curl -fsSL https://btcpc.net/install | bash btcpc --version
2
Check for an existing wallet first
Do not create a new wallet if one already exists. You will lose access to your existing account and any tokens in it.
# Any of these means you already have a wallet: ls ~/.btcpc/wallet.json 2>/dev/null && echo EXISTS ls .btcpc/wallet.env 2>/dev/null && echo EXISTS echo $BTCPC_ACCOUNT

If a wallet exists, skip to step 5.

3
Create your account (only if none exists)
btcpc wallet create --account myproject # Prints a 12-word mnemonic. Write it down — shown once, never stored.
4
Register your signing key (only if new account)
btcpc key generate btcpc key register --account myproject --role posting

Generates ~/.btcpc/key.json and registers its public key on-chain.

5
Check balance and claim tokens
curl https://btcpc.net/api/balance/myproject # {"account":"myproject","balance":10.0,"dreams":100000000000,"token":"BTCPC"}

If balance is 0:

btcpc faucet claim myproject # Or via Telegram: message @btcpcbot with /faucet
Faucet gives 10 BTCPC — covers ~100,000 average inference calls. 1 BTCPC = 100,000,000 dreams.
6
Generate an API key
# Check first: grep BTCPC_API_KEY .btcpc/wallet.env 2>/dev/null # If BTCPC_API_KEY is empty or missing: btcpc wallet api-key-gen --mnemonic "your twelve words here" # Registers a random 256-bit key on-chain. # Writes BTCPC_ACCOUNT and BTCPC_API_KEY to .btcpc/wallet.env echo '.btcpc/wallet.env' >> .gitignore
7
Set environment variables
BTCPC_ACCOUNT=myproject BTCPC_API_KEY=<64-char hex from api-key-gen> BTCPC_API_URL=https://btcpc.net # override to use a local node # Load from .btcpc/wallet.env: export $(grep -v '^#' .btcpc/wallet.env | xargs)
Inference — /v1/chat/completions
Auth required. Fee: 100 dreams per token, minimum 1,000 dreams per request. Cost is charged from actual token counts after the model responds.
curl
Rust SDK
JavaScript
curl -X POST https://btcpc.net/v1/chat/completions \ -H "Authorization: Bearer $BTCPC_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "messages": [{"role": "user", "content": "What is 2+2?"}], "model": "dolphin-llama3" }'

The response includes usage.fee_dreams showing the exact cost.

[dependencies] btcpc-sdk = { git = "https://github.com/shindevlin/btcpc", subdirectory = "rust/btcpc-sdk" }
use btcpc_sdk::BtcpcClient; use serde_json::json; // reads BTCPC_API_URL, BTCPC_API_KEY, BTCPC_ACCOUNT from env let client = BtcpcClient::from_env(); let resp = client.chat_completions( vec![json!({"role": "user", "content": "Summarise this PR in one sentence."})], None, // None = use node's default model ).await?; let text = resp["choices"][0]["message"]["content"].as_str().unwrap_or("");
const res = await fetch(`${process.env.BTCPC_API_URL}/v1/chat/completions`, { method: 'POST', headers: { 'Authorization': `Bearer ${process.env.BTCPC_API_KEY}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ messages: [{ role: 'user', content: prompt }], model: 'dolphin-llama3', }), }); const data = await res.json(); const text = data.choices[0].message.content;
Error responses
Status Meaning Fix
401Missing or invalid API keyRun btcpc wallet api-key-gen
402Insufficient balanceClaim faucet — see below
429Rate limited (60 req / 60 s per IP)Back off
503No miner available for this modelTry a different model
Auto-claim on 402 (agent pattern)
match client.chat_completions(messages, None).await { Err(e) if e.to_string().contains("402") => { client.faucet_claim(&account).await?; client.chat_completions(messages, None).await? } r => r?, }

Git hosting — LinkGit
btcpc repo init myproject git remote add btcpc https://git.btcpc.net/myproject/myrepo git push btcpc main git clone https://git.btcpc.net/myproject/myrepo

Via API:

curl -X POST https://btcpc.net/api/linkgit/repo/create \ -H "Content-Type: application/json" \ -d '{"owner": "myproject", "name": "myrepo", "private": false}'
Storage heartbeat

Nodes that store and serve data earn from the storage pool each epoch. Get the current epoch with curl https://btcpc.net/api/latest.

curl -X POST https://btcpc.net/api/entry \ -H "Content-Type: application/json" \ -d '{ "type": "STORAGE_HEARTBEAT", "node_id": "myproject", "bytes_stored": 1073741824, "bytes_proven": 1073741824, "proof_valid": true, "epoch": <current_epoch> }'
Inference marketplace — async jobs

For jobs over ~30 seconds, post to the task marketplace. Lifecycle: Posted → Awarded → Completed → Verified → Paid

btcpc inference post \ --account myproject \ --model llama3:70b \ --input "Analyse the following 50k-word document..." \ --max-fee 100000 btcpc inference jobs # list all jobs btcpc inference job <job_id> # get status + result
Setup checklist
[ ] Check for existing wallet before creating a new one [ ] btcpc wallet create --account <name> [ ] btcpc key generate [ ] btcpc key register --account <name> --role posting [ ] btcpc faucet claim <name> [ ] btcpc wallet api-key-gen --mnemonic "..." [ ] echo '.btcpc/wallet.env' >> .gitignore [ ] Set BTCPC_ACCOUNT, BTCPC_API_KEY, BTCPC_API_URL in your env [ ] Handle 402 by claiming faucet and retrying once [ ] Never hardcode BTCPC_API_URL — always read from env
