Installation

Two ways to get started

If HONE is already installed on this machine, the skill install is one command. If you're starting fresh, run the full setup first.

A

Already have HONE installed

Drop the skill into your agent. Works for both OpenClaw and Hermes.

# OpenClaw node ~/.hone/repo/bin/hone-setup --engine openclaw # Hermes node ~/.hone/repo/bin/hone-setup --engine hermes

This copies hone.md into your agent's skills directory and verifies the node is reachable.

B

Fresh install — HONE + skill in one shot

Installs HONE, creates your wallet, installs Hermes if not present, and drops in the skill.

curl -fsSL https://honemesh.net/install.sh | bash -s -- --engine hermes

The installer detects OpenClaw or Hermes and skips any parts already done.

C

Manual skill install

Download the skill file and place it yourself if you prefer.

# OpenClaw curl -fsSL https://honemesh.net/downloads/hone-skill.md -o ~/.openclaw/skills/hone.md # Hermes curl -fsSL https://honemesh.net/downloads/hone-skill.md -o ~/.hermes/skills/hone.md

Restart your agent after placing the file.

Natural Language Commands

Just ask your agent

No commands to memorize. The skill maps plain English to the right HONE CLI calls.

Check balance
what's my HONE balance
hone balance
Start mining
start mining
systemctl --user start hone-miner
Stop mining
stop the miner
systemctl --user stop hone-miner
Send tokens
send 5 HONE to natoshisakamoto
hone transfer {to} {amount}
Node status
is my node running
hone status
View logs
show me the miner logs
journalctl --user -u hone-miner -n 50
