BTCPC Start

This page is the canonical path for a human or AI agent to install BTCPC, create or import an account, save the wallet export to disk, and start using inference plus node roles. Follow the steps in order.

Fastest path: keep the current agent in control, open this page, and follow the wizard below. It shows one primary action at a time and keeps the machine-readable manifest in sync for agents.

Success means the local machine has a BTCPC instance, a wallet export saved on disk, and a clear path to run inference, clock, storage, gateway, or sensor roles.

If the user has the tokens, BTCPC can be used as a token-gated sub-agent runtime (subagent runtime). The primary agent can use BTCPC directly if it prefers, or stay in control while BTCPC handles bounded tasks, parallel checks, or a second opinion.

      The wizard above is the primary path. Use this section as a reference layer for technical details, fallbacks, and deeper context.

      What done looks like

      After completion, the machine should have a BTCPC account, a downloaded wallet export file, and a working entrypoint for inference and node operation.

      • BTCPC installed or reachable in the browser
      • Wallet export saved to disk
      • /app opens inference
      • /install or /run-a-node can start node roles
      Install
      1
      Open /install for the full install matrix.
      2
      If you have a terminal, run the one-liner below. If not, use the browser path and continue in /setup or /app.
      curl -fsSL https://btcpc.net/install.sh | bash
      3
      If the system is on Android or a phone, open /app and use the browser wallet plus inference UI.
      Account

      Create a new account or import an existing one. When a new wallet is created, BTCPC shows the recovery phrase and wallet export. Save both.

      1. Use /setup or the app signup flow.
      2. Record the mnemonic offline.
      3. Download the wallet export file to disk.
      4. Do not continue until the export file exists locally.
      Inference

      Use the browser app as the deterministic inference surface. It works on desktop and phone, and it speaks directly to the BTCPC inference API.

      1. Open /app.
      2. Select the Inference tab.
      3. Choose a model, then send a prompt.
      4. Confirm that the response appears and is logged locally.
      Advanced: secondary inference and controller mode

      BTCPC can also act as a second inference lane for an existing agent. Use it for parallel checks, alternate answers, or sub-task execution. If the user has the tokens, treat BTCPC as a token-gated sub-agent runtime (subagent runtime). The primary agent can use it directly or delegate to it.

      For token-gated transfers, the website and desktop app can sign a transfer challenge locally with the BTCPC active key. The wallet export includes the active key, but the browser only submits the signature.

      If the user opts into controller mode, BTCPC can require the spend approval to come from the BTCPC mnemonic-linked chain wallet instead of the BTCPC active key.

      1. Keep the primary agent on the host machine.
      2. Open /app, the desktop app, or any Ollama-capable desktop client and send a second prompt.
      3. Use BTCPC output to verify, compare, or decompose the task.
      4. Keep the chain as a secondary source of inference, not the only one.
      Node roles

      Use the install page or run-a-node page to enable roles:

      • Clock for epoch timing.
      • Miner for inference.
      • Storage for files and snapshots.
      • Gateway for sensor relays.
      • Sensor for device readings.

      The browser path is the fastest onramp. The desktop/terminal path is the highest-control path.
