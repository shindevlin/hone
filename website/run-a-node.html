Requirements

What you need

💻
GPU or CPU
Any Ollama-compatible GPU earns mining rewards. CPU-only? Run a clock or storage node — still earns.
💾
8 GB RAM minimum
16 GB recommended for 13B+ models. Storage and clock nodes run fine on 8 GB.
🖥️
Linux / macOS / Windows
Node.js 18+ and Ollama run everywhere. Native packages available for Linux and Windows.
🌐
Internet connection
Stable broadband. P2P port 6942 must be reachable for full node rewards.
Setup

Start mining in 3 steps

1

Install

Clone the repo and install dependencies. Takes about 60 seconds.

git clone https://github.com/shindevlin/btcpc.git && cd btcpc && npm install
2

Configure

Copy the example config and edit your username in. Run the interactive setup to register your account on-chain. Full setup guide →

# Copy the template, then open .env and set BTCPC_MINER to your username cp .env.example .env node bin/btcpc-setup
3

Mine

Start the mining daemon. Rewards arrive every 30-second epoch, scaled to your model's parameter count.

node bin/btcpc-mine --miner <yourname>
Rewards

What you earn

Rewards scale with verified parameter count from Ollama. Bigger model = more work = more BTCPC. Values below are approximate at genesis reward rate.

Model Size Example Models Approx BTCPC / epoch Per day (est.)
7B qwen2.5:7b, llama3.1:8b, mistral:7b ~12 BTCPC ~1,440
13B llama2:13b, vicuna:13b ~24 BTCPC ~2,880
27B gemma3:27b, qwen2.5:32b ~54 BTCPC ~6,480
70B llama3.3:70b, qwen2.5:72b ~135 BTCPC ~16,200

* Epoch = 30 seconds. Rewards are a share of the epoch pool, not fixed amounts. Actual earnings depend on total network compute at time of mining.

Node Types

Pick your role

⛏️
Miner
GPU recommended
Run Ollama inference. Work is verified on-chain. Highest reward potential — scales with model parameter count.
▲ Highest rewards
⏱️
Clock Node
Any hardware
Provide time attestations for network consensus. Raspberry Pi, old laptop, phone — anything with internet works.
▶ Stable small reward
💾
Storage Node
Disk space
Host BTCPC-FS blobs. Earn pay-per-delivery fees when your stored data is retrieved. No slash for absence.
▶ Pay per delivery
📶
Sensor Relay
IoT / GPS device
Forward GNSS, environmental, or Meshtastic readings to the chain. Earn per verified reading relayed.
▶ Pay per reading
