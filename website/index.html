01 — The Problem

Compute is wasted. Cloud is centralized.

The machines are everywhere. The work is waiting. The current system routes everything through the wrong hands.

  • GPUs burn electricity solving purposeless hashes — Bitcoin's PoW consumes ~150 TWh/year. The work proves effort. It produces nothing else. Those same GPUs could run AI inference that real people are already paying for.
  • Cloud computing is a $500B/year monopoly — AI inference, data storage, and application hosting are routed through a handful of corporations. Millions of devices with spare capacity sit idle or mine hashes nobody uses.
  • IoT hardware goes to waste — Helium miners, Raspberry Pis, LoRa gateways, Flipper Zeros — devices purpose-built for useful sensing work sit idle with nothing to do. There is no chain that pays for environmental data.

04 — Cross-Chain Bridge

Lock-and-recycle. Not burn-and-mint.

When you wrap BTCPC to wBTCPC on Base, your native tokens are locked 1:1. When you unwrap, they're released. No minting, no burning — just transfers between reserve pools.

Hard Cap Per Chain

Each destination chain has a hard cap of 4,200,000 wBTCPC (10% of native supply), pre-minted at deployment. This is not an arbitrary limit — it is the 42 constant applied to bridge design.

Bridge liquidity is provided by permissionless LPs who lock BTCPC with a variable commitment period (30 days to 4 years) and earn fees weighted by lock duration — the same veCRV model that powers Curve Finance.

Wrap fee: 0.05%. Unwrap fee: 0.20% (short lock), 0.15% (medium), 0.10% (long). Fees flow to LPs and btcpc_recycle — never burned.

05 — Four-Tier Finality

30 seconds to 3.5 days — every tier has a purpose

BTCPC state is anchored to external chains for independent verification. Working consensus runs fast. Deep finality anchors to Bitcoin.

Native BTCPC — every epoch

30-second epochs. Working consensus across the BTCPC P2P network. Fast enough for real-time inference markets and service delivery.

L2 (Base, Arbitrum) — every 100 epochs

~50 minutes. State root anchored to Base and Arbitrum for fast cross-chain verification. wBTCPC holders can verify BTCPC state without running a native node.

Ethereum — every 1,000 epochs

~8.3 hours. Deep finality anchor. Long-lived contracts and staking positions can checkpoint against Ethereum's security guarantees.

Bitcoin — every 10,000 epochs

~3.5 days. Ultimate anchoring. The most secure timestamp in existence. Not a dependency — a witness. BTCPC consensus does not wait for Bitcoin.

06 — Security

Protocol-level multi-factor authentication

BTCPC enforces 2FA at the consensus level. This is not wallet-level security — validators enforce authentication on every transaction.

Four-Key Hierarchy

Four key pairs derived from a single BIP-39 mnemonic: Owner (cold storage), Active (financial), Posting (mining operations), Memo (communication). A compromised mining rig cannot steal your funds.

Protocol-Enforced 2FA

Password-derived key signatures and TOTP (Google Authenticator compatible) enforced at the consensus level. Configurable per-account. Signed P2P messages enforced from v2.16.1+.

72-Hour Recovery

Submit a recovery request with the Owner key. A 72-hour time-lock begins on-chain. If the real owner contests during that window, the recovery is blocked. After 72 hours, 2FA resets safely.
