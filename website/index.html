01 — The Problem

AI compute is centralized. Mining energy is wasted.

Today, AI inference is controlled by a handful of corporations. Meanwhile, Bitcoin's network consumes 150 TWh annually producing nothing except SHA-256 hashes. There has to be a better way.

  • Single points of failure — one API outage affects millions of users. Censorship risk means providers decide what can and cannot be computed. Monopoly pricing extracts rent on compute that costs fractions of a cent.
  • Wasted proof of work — Bitcoin's security model works, but the computational output serves no secondary purpose. The energy spent mining produces nothing except hashes that prove work was done.
  • Siloed liquidity — every new blockchain launches with zero liquidity. Cross-chain bridges are complex, expensive, and frequent targets of exploits. There is no mechanism for organic multi-chain value creation.

06 — Security

Protocol-level multi-factor authentication

BTCPC is the first blockchain with protocol-enforced 2FA. This is not wallet-level security — it is consensus-level. Validators enforce authentication on every transaction.

Hive-Style Key Hierarchy

Four key pairs derived from a single BIP-39 mnemonic: Owner (cold storage), Active (financial), Posting (mining operations), and Memo (encrypted communication). A compromised mining rig cannot steal your funds.

Protocol-Enforced 2FA

Two additional authentication factors at the consensus level: password-derived key signatures and TOTP (Google Authenticator compatible). Configurable per-account — from password-only to full multi-factor.

72-Hour Recovery

Lost your 2FA? Submit a recovery request with the Owner key. A 72-hour time-lock begins on-chain. If the real owner contests during that window, the recovery is blocked. After 72 hours with no contest, 2FA resets safely.

07 — Privacy

End-to-end encrypted inference

All inference on the BTCPC chain is end-to-end encrypted. This is not optional. No plaintext prompt or result ever touches the chain or is visible to validators, other nodes, or the public.

Encrypted Inference

Prompts are encrypted with the compute node's memo key. Results are encrypted back with the requester's memo key. On-chain, only hashes and ciphertext exist. No plaintext, ever. Always on, mandatory.

Anonymous Routing

Submit inference requests through a relay mixer. Requests route through relay nodes that strip your identity before forwarding to the compute node. Nobody can link the request to you. Optional per-request.

Stealth Accounts

One-time addresses derived from the recipient's public key that cannot be linked back to their main account. Each transaction generates a new stealth address. An observer sees transfers between unrelated accounts.

Node IP Privacy

Mining nodes can expose their endpoint as a Tor hidden service or I2P address. No one can determine the physical location of a compute node. ISPs cannot see that a machine is running a BTCPC node.
