BTCPC on Windows

One PowerShell command. No git clone, no WSL, no bash, no curl alias tricks.

1Install Docker Desktop (optional — the script does it for you)

You do not need to install Docker Desktop manually. The BTCPC starter script checks for Docker automatically and will download and install it silently if it is missing. If Docker Desktop is already installed but not running, the script will launch it for you and wait up to 10 minutes for it to be ready.

Nothing to do here. Just run the command in Step 3 and the script handles everything — Docker install, Docker startup, image download, and mining launch — without asking you to do anything.
2Open PowerShell

Press the Windows key, type PowerShell, and press Enter. A blue (or black) window will open.

Important: Use PowerShell, not cmd.exe, not WSL, not Git Bash. This matters because curl in PowerShell is an alias that trips on the commands — the script below uses PowerShell-native commands that work correctly.
3Paste this command and press Enter

Click the orange button to copy, then right-click in PowerShell to paste, then press Enter. The first line forces TLS 1.2 (older PowerShell defaults to TLS 1.0/1.1, which Cloudflare refuses — that's the most common cause of "connection error").

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm https://btcpc.net/btcpc-start.ps1 | iex

The shorter irm https://btcpc.net/btcpc-start.ps1 | iex works on PowerShell 7+, but the version above is bulletproof on every Windows since 7.

That downloads the BTCPC starter script and runs it. The script will:

  • Verify Docker is installed and running
  • Create C:\Users\you\btcpc as the working folder
  • Download docker-compose.yml and the ~200 MB BTCPC image tarball
  • Load the image into Docker
  • Ask for your BTCPC username (create one via @btcpcbot on Telegram if you don't have one)
  • Start mining
Success looks like: green [OK] lines for each step, then BTCPC is running as yourname at the end with a list of running containers. Check your balance in Telegram with @btcpcbot /balance after a few minutes.
4Troubleshooting

The BTCPC installer is designed to fix problems automatically without asking you to do anything. Here is what it handles on its own — just keep the window open and wait:

  • TLS / connection errors — the installer already forces TLS 1.2 at startup. It handles this automatically.
  • Docker not installed — the installer downloads and runs the Docker Desktop installer silently, then waits for it to finish. You do not need to go to docker.com.
  • Docker engine not running — the installer launches Docker Desktop for you and polls every 5 seconds for up to 10 minutes until it is ready.
  • Image download fails — the installer retries automatically up to 5 times with increasing wait times (5 s, 15 s, 45 s, 2 min, 5 min).
  • Corrupt image tarball — the installer deletes the broken file, re-downloads, and retries the load automatically.
  • docker compose fails — the installer sleeps 30 seconds and retries from the beginning automatically.
  • No username entered — the installer generates a guest name like guest-a1b2c3d4 and continues. You can link it to your real account later via @btcpcbot.
In short: if the window is open and showing [BTCPC] Working... messages, it is fixing itself. Just wait. Do not close it.

Still stuck after 30+ minutes with no progress? Run these diagnostic commands in a new PowerShell window and share the output with Shin on Telegram:

docker --version; docker info; docker images btcpc; Get-Content $HOME\btcpc\docker-compose.yml
