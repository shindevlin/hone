BTCPC on Windows

One PowerShell command. No git clone, no WSL, no bash, no curl alias tricks.

1Install Docker Desktop

Download from docker.com/products/docker-desktop, run the installer, and reboot when prompted. After reboot, launch Docker Desktop from the Start menu and wait for the whale icon 🐳 in your system tray to stop animating (takes 2-3 minutes on first launch).

Already installed? Just make sure the whale icon is in your system tray and not animating. If it's not there, launch "Docker Desktop" from the Start menu.
2Open PowerShell

Press the Windows key, type PowerShell, and press Enter. A blue (or black) window will open.

Important: Use PowerShell, not cmd.exe, not WSL, not Git Bash. This matters because curl in PowerShell is an alias that trips on the commands — the script below uses PowerShell-native commands that work correctly.
3Paste this command and press Enter

Click the orange button to copy, then right-click in PowerShell to paste, then press Enter.

irm https://btcpc.net/btcpc-start.ps1 | iex

That downloads the BTCPC starter script and runs it. The script will:

  • Verify Docker is installed and running
  • Create C:\Users\you\btcpc as the working folder
  • Download docker-compose.yml and the ~200 MB BTCPC image tarball
  • Load the image into Docker
  • Ask for your BTCPC username (create one via @btcpcbot on Telegram if you don't have one)
  • Start mining
Success looks like: green [OK] lines for each step, then BTCPC is running as yourname at the end with a list of running containers. Check your balance in Telegram with @btcpcbot /balance after a few minutes.
4Troubleshooting

"cannot be loaded because running scripts is disabled" — your execution policy blocks .ps1 files. The irm | iex pattern normally bypasses this, but if it doesn't work, first run:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

"The term 'docker' is not recognized" — Docker Desktop isn't installed, or Windows hasn't picked up the new PATH since the install. Reboot and try again.

"Cannot connect to the Docker daemon" — Docker Desktop is installed but not running. Launch Docker Desktop from the Start menu, wait for the whale icon to stop animating, then re-run the command.

Stuck at "no such image" — your previous attempt left a broken cache. Run these lines one at a time to reset and retry:

cd $HOME\btcpc; Remove-Item btcpc-image.tar.gz -ErrorAction SilentlyContinue; docker image rm btcpc:latest -f 2>$null; irm https://btcpc.net/btcpc-start.ps1 | iex

Still stuck? Open a new PowerShell window and run these diagnostic commands one by one, then share the output with Shin:

docker --version; docker info; docker images btcpc; Get-Content $HOME\btcpc\docker-compose.yml
