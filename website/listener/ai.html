Built so it can't be tricked

  • Only from honemesh.netThe assistant can't hand it a download link. Every file comes from honemesh.net/app/listener/.
  • Checked before anything runsThe release list must be signed by HONE's release key, which is built into the tool, and the installer must match its sha256 fingerprint.
  • You say yes firstThe first call only checks and explains. The installer runs only after you agree.
  • Read-only account keyTo read your birds it uses a key that can't change anything on your account.

Human conversation is automatically deleted. The listener only keeps a count of voices it removed. No audio is ever saved or sent; only a short bird report every 15 minutes.

Set it up

1. Get your AI key (optional, for your birds)

Open honemesh.net/me, sign in, and tap Make an AI key. It starts with w_ and can only read your birds and listeners. You can skip this to just install the listener; the setup page will sign you in.

2a. Claude Desktop

Needs Node.js 18 or newer. In Claude Desktop open Settings, Developer, Edit Config, and add:

{
  "mcpServers": {
    "hone-listener": {
      "command": "npx",
      "args": ["-y", "https://honemesh.net/app/mcp/hone-listener-mcp-0.1.0.tgz"],
      "env": { "HONE_TOKEN": "paste your w_ key here" }
    }
  }
}

Restart Claude Desktop, then ask: "Set up the HONE bird listener on this computer."

2b. Claude Code

claude mcp add hone-listener -e HONE_TOKEN=w_your_key -- npx -y https://honemesh.net/app/mcp/hone-listener-mcp-0.1.0.tgz

2c. Just ask about your birds (no install)

A read-only version runs at https://honemesh.net/listener/mcp. It can't install anything; it answers my_birds, is_back and listener_status with your key:

claude mcp add --transport http hone-birds https://honemesh.net/listener/mcp --header "Authorization: Bearer w_your_key"

What the assistant can do

ToolWhat it does
install_listenerFinds your operating system, downloads the signed release from honemesh.net, checks the signature and fingerprint, and tells you. With your OK it installs. An invite code (ref) is passed to the setup.
listener_statusIs the listener running on this computer, and is each of your listeners "Listening now" or when did it last report?
my_birdsThe birds your listeners heard, newest first. Narrow it with "today", "week", "48h" or a date.
is_backHas this bird come back? When it was last heard, and how long it was away before that.

Coming later: named birds. When your listener recognizes the same bird returning, you'll be able to name it and ask about it by name.
