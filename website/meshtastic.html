One-Command Setup

Connect your Meshtastic device via USB and run:

curl -fsSL https://btcpc.net/meshtastic-setup.sh | bash

This adds the btcpc channel to your device. Then start the bridge:

node bin/btcpc-meshtastic --account your-name

The bridge auto-detects your device on USB and starts relaying. It reconnects automatically if the device disconnects.

How Mesh Relay Works

1

Device joins mesh

Your Meshtastic radio joins the "btcpc" channel on the mesh network. Any device in range can send BTCPC sensor packets.

2

Bridge relays data

The bridge daemon reads packets from your device over USB and submits sensor readings to the BTCPC chain via the local node API.

3

Chain records it

Each reading is recorded on the BTCPC blockchain with the relay node credited. Verifiable, permanent, and useful data.

4

You earn BTCPC

Relay operators earn a share of the IoT sensor pool every epoch. More data relayed means more earned. No mining rig needed.

What You Earn

BTCPC rewards come from the IoT sensor pool. Every epoch, active relay nodes receive a share proportional to the data they contributed.

Relay Fees

Every sensor packet you relay from the mesh to the chain earns a small relay fee from the IoT pool.

Own Device Sensors

Your Meshtastic device's GPS, battery, and signal strength are reported as sensor data and earn rewards too.

Network Coverage

Devices that extend mesh coverage to new areas earn a coverage bonus, incentivizing geographic spread.

BTCPC Mesh Packet Format

Devices send JSON text messages on the "btcpc" channel:

// Sensor reading packet
{"btcpc":1,"sensor":"josh/flipper-subghz","value":-92,"meta":{"freq":"433MHz"},"sig":"abc123"}

Fields:

btcpc — must be 1 (identifies as BTCPC packet)
sensor — sensor ID in account/name format
value — numeric reading value
meta — optional metadata object
sig — optional signature (for trusted relay mode)
