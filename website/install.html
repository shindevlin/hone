Install BTCPC

Five ways to join the network. Pick the one that fits — from one-click desktop apps to terminal one-liners. All paths produce a working node.

EASIEST 🖥️
Desktop App
macOS · Windows · Linux

One-click install. Zero terminal. GUI for everything. The native app downloads everything you need and starts mining with a single button.

  • System tray icon, auto-start on boot
  • GUI dashboard: balance, stats, settings
  • Auto-updates to latest version
  • ~40MB download
Download for Your OS 🐳
Docker
Mac · Linux · Windows (Docker Desktop)

If you have Docker Desktop installed, this is the fastest path. One command brings up the entire stack: MongoDB, Ollama, and the BTCPC node.

  • Fully isolated, easy to remove
  • No system pollution
  • Auto-restart on crash
docker compose up -d
 ⌨️
Terminal
macOS · Linux · WSL

For technical users. One curl command installs Node.js, Ollama, downloads the model, creates an account, and starts mining. Then runs as a background service.

  • Auto-detects hardware (GPU/CPU/RAM)
  • Configures systemd service
  • No GUI dependencies
curl https://btcpc.net/install.sh | bash
 📱
Android (Termux)
Permanent clock node on your phone

Runs in the background, survives sleep, auto-updates hourly. Best for "always on" phone clocking. Add to home screen as a PWA.

  • Survives screen-off and reboots
  • Auto-updates every hour
  • 3-tap install via Termux
Install on Android → 🌐
Browser Clock
Any device with a browser

Run a clock node in your browser. No download, no installation. Just open the page and earn 5% block rewards split among all clocks. Tab must stay open.

  • Zero install, zero config
  • Earns clock rewards while open
  • Works on mobile, tablet, desktop
Open Browser Clock → 💬
Telegram Wallet
No installation needed

Just want a wallet? Message @btcpcbot on Telegram. Send commands like /create, /balance, /transfer. No mining, just holding and sending BTCPC.

  • Wallet only — no mining
  • Receive cross-chain claims
  • Buy via @btcpcwalletbot
