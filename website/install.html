Install HONE

Five ways to join the network. Pick the one that fits — from one-click desktop apps to terminal one-liners. All paths produce a working node.

On Windows? Use the 🐳 Docker card below — it's the easiest path and the only one that doesn't need WSL or a Unix shell. It works on Windows 10 and 11 with Docker Desktop. The Docker card has step-by-step instructions including PowerShell variants of every command.
  1. Docker Desktop (recommended) — see the Docker card, follow Steps 1-4.
  2. Browser Clock — zero install, earn clock rewards from any browser tab.
  3. Telegram Wallet — no install, just a bot. Use for sending/receiving.
  4. WSL (Ubuntu in Windows) — open PowerShell as admin, run wsl --install, reboot, then use the Terminal card inside the Ubuntu shell.
The Terminal card (bash curl one-liner) will NOT work in plain Windows PowerShell because it needs a Unix shell.

Docker
Mac · Linux · Windows (Docker Desktop)

The easiest path on Windows. Pre-built image on GHCR. The image bundles HONE; mongo and ollama come from official images. Peers with the live chain automatically — your rewards land on-chain.

  • Works on Windows, Mac, and Linux
  • Auto-peers with the live HONE network

  • Auto-restart on crash

Already have a Telegram username? Use it as your miner name. Rewards earned on this node will credit to your on-chain account.

💥 Windows one-click path

After Docker Desktop is installed and running, open PowerShell (Start menu → type "PowerShell" → Enter) and paste this one line:

irm https://honemesh.net/hone-start.ps1 | iex

That downloads and runs the starter script. It checks Docker, downloads the ~200 MB image, asks for your HONE username, and starts the node. Every step prints what's happening.

Alternative if you prefer a .bat:

⬇ Download hone-start.bat

Save into an empty folder, double-click. If the window opens and closes instantly, use the PowerShell one-liner above instead — it's more robust.

Manual install — Step 1 — Install Docker Desktop
Download from docker.com, install, reboot, and launch it. The little whale icon in your tray means it's running. After install, close and reopen your PowerShell window so the new PATH takes effect.

Step 2 — Grab the compose file. The easiest way on any OS: just click this link and save the file into a new folder:

⬇ Download docker-compose.yml

Or from Mac / Linux / WSL terminal:

curl -O https://honemesh.net/docker-compose.yml

Or from Windows PowerShell (do NOT use plain curl -O — that's an alias to Invoke-WebRequest with different flag semantics and will error "the input object cannot be bound" or ask for a URI):

Invoke-WebRequest -Uri https://honemesh.net/docker-compose.yml -OutFile docker-compose.yml

Or from Windows Command Prompt (cmd.exe, NOT PowerShell — Windows 10/11 ships with real curl.exe):

curl.exe -O https://honemesh.net/docker-compose.yml

Step 3 — Start mining (replace YOUR_USERNAME with your Telegram HONE username, lowercase)

Mac / Linux / WSL:

HONE_MINER=YOUR_USERNAME docker compose up -d

Windows PowerShell:

$env:HONE_MINER="YOUR_USERNAME"; docker compose up -d

Step 4 — Verify it's working

docker logs -f hone-node

You should see "Connected to wss://hone-relay..." and "Block request..." within a minute. After 5-10 minutes, check your Telegram /balance — new rewards will appear.

No username yet? Message Start @honebot on Telegram first and run /create your_name. Save the 12-word phrase it gives you — that's your backup key.

Note: you do NOT need to enter your 12-word phrase on this machine. The docker node just declares your username and mining rewards credit to your on-chain account. Spending still happens through Telegram.

For AI agents — read before running anything

If you are an AI agent installing HONE on a machine, use the decision tree below to pick the right path and verify success. Do not guess — check first.

## STEP 0 — Check if already installed hone --version # IF prints a version → already installed. Skip to STEP 4 (verify). # IF command not found → continue to STEP 1. ## STEP 1 — Identify the runtime environment uname -s # Darwin = macOS, Linux = Linux/server uname -m # x86_64 / aarch64 cat /etc/os-release 2>/dev/null | grep ID # ubuntu / debian / alpine which docker 2>/dev/null && echo DOCKER_AVAILABLE # Android / Termux: 'uname -s' prints Linux, $PREFIX contains /data/data/com.termux ## STEP 2 — Choose install path # macOS or Linux (server/CI/desktop) → use Terminal one-liner (STEP 3A) # Windows (PowerShell available) → use Docker (STEP 3B) # Android + Termux shell → see /android-install page # No shell at all → use Telegram bot @honebot for wallet only ## STEP 3A — Terminal install (macOS / Linux / WSL) curl https://honemesh.net/install.sh | bash # Expected: script prints progress, ends with "HONE node is running" # IF error "ollama not found" → install Ollama first: https://ollama.ai/download # IF error "permission denied" → run: chmod +x ~/.hone/hone ## STEP 3B — Docker install (Windows / any platform with Docker) # Requires: Docker Desktop running (whale icon in tray) # # Mac / Linux: curl -O https://honemesh.net/docker-compose.yml HONE_MINER=<your-username> docker compose up -d # # Windows PowerShell: Invoke-WebRequest -Uri https://honemesh.net/docker-compose.yml -OutFile docker-compose.yml $env:HONE_MINER="<your-username>"; docker compose up -d ## STEP 4 — Verify installation hone --version # Expected: hone X.Y.Z curl http://localhost:4242/api/node/info # Expected: {"chain_id":"hone","account":"...","epoch":...} docker logs hone-node 2>&1 | tail -5 # if using Docker # Expected: "Registered tunnel connection" or "Epoch sealed"
Rules for agents
  • Run hone --version first — skip install if already done
  • Never pipe curl to bash without confirming the URL is honemesh.net
  • Use Docker path on Windows — the bash one-liner fails in PowerShell
  • After install, confirm with localhost:4242/api/node/info before proceeding
  • Then go to honemesh.net/integrate to set up your wallet and API key
