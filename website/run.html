Windows FREE
Works on Windows 10 & 11
1
Install Docker Desktop
Free download. Run the installer, reboot, then start Docker Desktop. You'll see a little whale icon in your taskbar when it's ready.
Download Docker →
2
Open PowerShell and paste this
Press the Windows key, type "PowerShell", press Enter. Then paste:
irm https://honemesh.net/hone-start.ps1 | iex
The script asks for your HONE username, downloads the node, and starts it. That's it.
3
You're done
Your node starts automatically. Open honemesh.net/app to see your balance grow.
🍎 🐧
Mac or Linux FREE
macOS 12+ · Ubuntu · Debian · any Linux
1
Open Terminal
On Mac: press ⌘ Space, type "Terminal", press Enter.
On Linux: press Ctrl+Alt+T.
2
Paste this one line
curl -fsSL https://honemesh.net/install.sh | bash
It installs everything, asks which roles to run (clock / miner / full), and starts the node.
3
You're done
Check your balance at honemesh.net/app. Rewards arrive every 30-second epoch.
📱
Android Phone FREE
Android 8+ · runs in background
1
Download the APK
Direct APK install — no app store needed. Open your browser on Android and go to:
honemesh.net/android
2
Install and open the app
If Android says "install from unknown sources", tap Settings and allow it for your browser. Then install and open HONE.
3
Enter your username — done
The app runs a clock node in the background. It earns while your phone is charging.
