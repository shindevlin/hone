# DEPRECATED — Node.js Prototype

This directory (`src/`) contains the legacy Node.js/Express implementation of HONE (v3.x era).

**It is not running. It is not maintained. Do not modify or reference it.**

The active node is in `rust/hone-node/` — a single Rust binary using libp2p, RocksDB, and Axum.

All new development goes in Rust. This directory is kept only until a formal archive/deletion pass.
